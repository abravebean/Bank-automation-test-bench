What's being tested

Ledgerline, a fictional demo bank with accounts and transfers, and the tooling that tests it.

  • Banking rules: boundary values, daily limits, overdraft protection
  • Security: cross-account access (IDOR), lockout, session cookies
  • Ledger integrity and race conditions (no double spending)
  • Playwright (TypeScript) and Selenium UI tests on Chromium, Firefox and WebKit
  • BDD scenarios in Gherkin
  • REST API contract tests with JSON Schema
  • SQL data-integrity tests against PostgreSQL
  • Postman collections run with Newman
  • Performance (p95 latency) and accessibility (WCAG 2.1 AA)
  • A click-to-code test recorder (Playwright Codegen)
  • AWS infrastructure as code (CDK) with its own tests
